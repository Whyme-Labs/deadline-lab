# Laboratory execution only

This is not a certified controller, production fault injector or security boundary. It must not control physical machinery.

The original scenarios can signal only their own child workers. The external adapter starts its own foreground nginx process, uses loopback sockets and confines file effects to a fresh output directory. It does not edit or reload a system nginx service. It verifies the private startup token before mutations. Scenario files cannot select external PIDs, addresses, executable paths or shell commands.

A command-line binary path is trusted operator input. The HTTP hook endpoint is for this local controlled experiment only. Do not expose it publicly or attach it to production services. Cooperative hooks intentionally disrupt laboratory operations.

Counts, waits and output sizes are bounded. Children are cleaned up and output directories cannot silently overwrite existing runs. Integrity hashes detect accidental corruption, not a malicious actor able to rewrite both files and manifests.

The QNX adapter requires an authorised lab target. It does not change permissions, install drivers, request hardware access or distribute licensed material. Missing prerequisites produce NOT_RUN or an infrastructure error.

Do not upload SDK files, target images, credentials, confidential project data or proprietary recordings in a public submission. No native platform, physical safety or durable action guarantee follows from a passing local test.
